# Hospital-Management-System
A Java-based application for managing patients, doctors, appointments, and hospital operations.
The Hospital Management System (HMS) is a structured Java application designed to streamline hospital operations by managing patient records, doctor details, appointments, billing, and administrative tasks. It provides an efficient and organized way to store, retrieve, and process medical data, improving workflow and reducing manual errors.

✨ Features

✔ Patient Management
Add, update, delete, and view patient details including personal info, diagnosis, and history.

✔ Doctor Management
Maintain doctor profiles, specialization, availability, and assigned patients.

✔ Appointment Scheduling
Book appointments between patients and doctors with time and date management.

✔ Billing System
Generate invoices with consultation fees, room charges, tests, and medication cost.

✔ Search Functionality
Quickly search patients and doctors using IDs or keywords.

✔ Role-Based Access
Admin, doctor, and receptionist modules.
